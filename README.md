# glowrate-selfie-scorer

An AI-powered facial feature analyzer and selfie rating tool built with React Native and Expo.

Built using **React Native (Expo)**.

### Setup and Installation

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the Expo development server:
   ```bash
   npx expo start
   ```
3. Scan the QR code with your iOS Camera app or the Android Expo Go app to run the application.
